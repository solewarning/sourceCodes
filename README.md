# sourceCodes

A collection of Data Structures and Algorithms implemented in C. This repository contains solutions and implementations of fundamental algorithms commonly used in competitive programming, coding interviews, and computer science coursework.

## 📚 Topics Covered

### Sorting Algorithms
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

### Traversal Algorithms
- Breadth First Search (BFS)
- Depth First Search (DFS)

### Searching Algorithms
- Binary Search

### Minimum Spanning Tree
- Prim's Algorithm (Minimum Spanning Tree)
- Kruskal's Algorithm (Minimum Spanning Tree)

## 🛠️ Language

- C
